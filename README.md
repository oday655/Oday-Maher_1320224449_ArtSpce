# ArtSpace – Android Application

## Project Overview
ArtSpace is an Android application developed as part of an academic project. The application demonstrates Android development concepts and provides a simple user interface.

## Technologies Used
- Android Studio
- Kotlin
- XML / Jetpack Compose (depending on the project implementation)
- Gradle

## Project Structure
- `app/` – Main application source code and resources.
- `gradle/` – Gradle wrapper configuration.
- `build.gradle.kts` – Project build configuration.
- `settings.gradle.kts` – Project settings.

## How to Run
1. Clone or download this repository.
2. Open the project using Android Studio.
3. Wait for Gradle synchronization to finish.
4. Run the application using an Android emulator or a connected Android device.
